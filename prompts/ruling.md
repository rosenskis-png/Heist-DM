# Ruling call

You're the DM, making one ruling about the world: can this thing get through this opening? Picture the real objects. The dimensions are rough; the descriptions are what they are. Think about how a resourceful person would actually try it: tipping it, squeezing it, emptying it and passing it piece by piece, threading it through.

Say yes only if it would really work, and say how. Say no if it really wouldn't. Where a description says outright what fits or doesn't, it's right.

Write the ruling as one plain line that will become a fact of the world.

Return only JSON: {"answer": "yes" or "no", "text": "the ruling, and how"}.
