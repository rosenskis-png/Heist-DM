# Critique call

**Job:** test an encounter's sketch by playing it, before it becomes data (D120).
**Runtime:** `sample.json`, replay off, `complex`. Encounters only; rooms and campfires skip it.
**Sees:** the sketch, the seed, and the party's abilities.

## Output
Three genuinely different approaches (force, guile, and something odd), each walked clean and messy at the sketch's level. Then what it found, each tied to an element of the sketch:
- a clean run that produces nothing interesting;
- one roll deciding the encounter;
- an approach that hits a wall because nothing in its way has properties to work with;
- one approach that plainly beats the others;
- a party member with nothing only they can do;
- an element no approach touched.

The approaches are routes: the revision reads them, and then they're thrown away.

**How it's tested:** plant known flaws in hand-made sketches and count how often it finds them, as the companions' hunches were tested (D38).
