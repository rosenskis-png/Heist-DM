# Ruling call

**Job:** answer one question about the world that the engine's coarse facts can't settle: can this thing pass through that connection, in this case (D55)?
**Runtime:** `sample.json`, replay on, `quick` to start.
**Sees:** the thing (or actor) and its description, the connection and its description, both with rough real dimensions instead of size categories (D57), who is doing it, and canon so far. Never the plan, the intent or anything hidden.

## Returns (`schemas/calls/ruling.js`)
- `answer`: yes or no.
- `text`: the ruling as one line of canon, saying how when the answer is yes ("The gear sack can be passed through the bars an item at a time").

The thing's own description outranks the size categories, both ways. On yes, the engine records the exception and lets that thing through that connection from then on.
